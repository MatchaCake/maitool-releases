# maitool

舞萌 DX 国服**只读**查询工具（Windows / macOS / Android）。这个仓库只用来发布安装包，源码不公开。

## 功能

- 扫码登录（粘贴二维码字符串或链接，或识别图片）
- 概览：昵称、Rating、登录与封禁状态
- 全部成绩、B50、PC50，自绘海报导出
- 收藏品、旅行伙伴、地图、万花筒、功能票（只读），对照本地游戏数据显示已拥有 / 未拥有
- 账号备份导出 JSON
- 从本地游戏目录导入 Sinmai 曲库与收藏品目录

## 不做什么

- **不修改任何服务器数据**：不上传成绩、不解锁、不发票、不改数值。代码只允许查询接口和必需的登录 / 登出。
- 安装包里**不含任何官方密钥、机台身份或游戏素材**。首次使用需要自行导入协议配置并填写机台身份。
- 没有统计上报，不开本地网络端口。

## 使用须知

- 游戏服务器只接受中国大陆 IP。不在大陆请在设置里配置自己的代理，否则工具不会发出请求。
- 每次查询都会在服务器上留下一次登录 / 登出记录。工具限制了同一账号的登录间隔和请求频率，但**任何第三方工具都有封号风险，请自行承担**。
- 本工具与 SEGA、华立无关。

## 安装

- **Android**：下载 `maitool-android-arm64.apk`（绝大多数手机）；老设备或模拟器用 `maitool-android-universal.apk`。
- **macOS**（13 及以上）：下载 `maitool-macos.zip` 解压，首次打开需右键 →「打开」（未经 Apple 公证）。
- **Windows**：暂未提供。
